
# TC-20: Verify Navigation to View Data Screen via Actions Menu

| **Field** | **Description** |
|---|---|
| **Test Case ID** | TC-20 |
| **Title** | Verify that clicking the "View Data" option in the Actions menu redirects the user to the selected student's data view page. |
| **Preconditions** | 1. User is logged into the application workspace.<br>2. User is on the **Caseload** screen with at least one student listed. |
| **Test Data** | **Target Student:** Any existing student record in the caseload table. |
| **Steps** | 1. Navigate to the **Caseload** page.<br>2. Locate a student entry in the list.<br>3. Click the three-dots (⋮) **Actions** menu button on the right side of the row.<br>4. Click the **View Data** option.<br>5. Verify that the user is redirected to the selected student's data tracking/view page. |
| **Expected Result** | The application should successfully navigate the user to the **View Data** screen corresponding to the selected student record. |
| **Actual Result** | The **View Data** option successfully redirected the user to the student's data view/analytics interface as expected. |
| **Status** | **PASS** |
