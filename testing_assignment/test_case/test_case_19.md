
###  Navigation to Edit Student Modal

# TC-19: Verify Navigation to Edit Student Modal via Actions Menu

| **Field** | **Description** |
|---|---|
| **Test Case ID** | TC-19 |
| **Title** | Verify that clicking the "Edit Student" option in the Actions menu opens the Edit Student interface or modal. |
| **Preconditions** | 1. User is logged into the application workspace.<br>2. User is on the **Caseload** screen with at least one student listed. |
| **Test Data** | **Target Student:** Any existing student record in the caseload table. |
| **Steps** | 1. Navigate to the **Caseload** page.<br>2. Locate a student entry in the list.<br>3. Click the three-dots (⋮) **Actions** menu button on the right side of the row.<br>4. Click the **Edit Student** option.<br>5. Verify that the Edit Student modal or page opens with the selected student's details pre-populated. |
| **Expected Result** | The application should successfully open the Edit Student interface with the selected student's existing details pre-populated and available for editing. |
| **Actual Result** | The **Edit Student** option successfully opened the Edit Student interface with all student fields pre-populated. |
| **Status** | **PASS** |
